# WILDBOUND distributable asset inventory

The packaged WILDBOUND runtime retains only the following binary assets under `app/src/main/assets/www`:

- `models/characters/kaykit_v1_2/Animations/gltf/KayKit_AnimatedCharacter_v1.2.glb` — KayKit Animated Character v1.2, CC0, with the original package license retained beside it.
- `textures/forest_floor_basecolor.png` — original deterministic procedural base-color map.
- `textures/forest_floor_roughness.png` — original deterministic procedural roughness map.
- `textures/forest_floor_height.png` — original deterministic procedural height map.

The three terrain maps are generated by `apply_v6_procedural_asset_replacement.py`. `PROCEDURAL_ASSET_PROVENANCE.json` is reduced to these retained files and includes their generator version, byte sizes and SHA-256 hashes. `create_asset_provenance_ledger.py --require-verified` must report zero unverified files before release.

Unused BattleZone branding, portraits, loading artwork, sprites, voice packs, legacy model bridges, legacy stylesheets and unused model/texture packs are removed from the distributable project. Runtime audio effects are synthesized locally through Web Audio.
